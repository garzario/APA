# Capital Circles

Your financial hub for families, friends, and roommates. Support each other's financial goals without mixing finances.

## Track 2: Human-Centered Connection

Capital Circles transforms banking from a solo experience into a shared one, where families and friends support each other's financial goals without compromising privacy, powered by smart insights and Capital One card optimization.

## Features

- **Circles** - Create groups (family, roommates, friends, couples) with role-based privacy
- **Smart Statements** - AI-generated narrative summaries of your spending
- **Card Selector** - Know which Capital One card to use for every purchase
- **Financial Wellness** - Proactive nudges and goal tracking

## Tech Stack

- Swift 5.9 / SwiftUI
- iOS 17+ (Charts, Observable macro)
- Claude AI for Smart Statements
- MVVM architecture

## Setup

1. Install [XcodeGen](https://github.com/yonaskolb/XcodeGen): `brew install xcodegen`
2. Run `xcodegen generate` in the project root
3. Create `CapitalCircles/Secrets.swift` from `Secrets.example.swift`
4. Open `CapitalCircles.xcodeproj`
5. Set your development team in Signing & Capabilities
6. Build and run
